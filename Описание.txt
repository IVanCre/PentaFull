
Данный проект -это клиент-серверный мессенджер.

----------------------------
Penta_Server	- сервер ASP.
Penta_CleintLib - библиотека-ядро клиента.
MessageLib		- бибилотека описывающая сущность Сообщения и связывающая проекты Penta_Server и Penta_CleintLib
Client			- кроссплатформенный клиент на MAUI. Приоритет отдан для android. Является надстройкой над Penta_CleintLib.
----------------------------

Основная передача данных между клиентом и сервером идет через signalR c аутентификацией по jwt-токенам.
Часть первичных запросов реализованы на https(регистрация и админ-функции).
Пуш-оповещения идут через гугловскую firebase( https://console.firebase.google.com/project/penta-client-1928/settings/serviceaccounts/adminsdk)
Для отладки-управления сервером используется web-морда swagger.

Хранение данных на сервере осуществляется через EF( на 16.04.2026 это mssql)
Хранение данных на клиенте осуществляется через SQLite.

Для тестирования используется TestUtils\ConsoleClient_Tests - упрощенная консольна реализация Client.
Единовременно может работать 1 экземпляр, т.к. создается БД SQLite по адресу C:\Users\user\AppData\Roaming\PentaClientDB.db3
Автотесты не пишу, т.к. разработку веду в одно лицо.
В локальном гите веду 1 ветку, чтоб можно было откатиться при случае.

Для шифрования используется самоподписной сертификат, который физически лежит в папке с сервером
